# 136. 只出现一次的数字

[力扣原题](https://leetcode.cn/problems/single-number/) · 简单 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

数组里一个数出现一次，其余都出现两次，找出唯一的数。

## 怎么想到这个方法

**异或抵消成对数字**

异或满足交换律、结合律，且 x^x=0、0^x=x。把所有数依次异或起来，出现两次的数无论隔多远都会互相抵消，只剩出现一次的数。无需排序，也不需要统计表。

## 跟着例子走一遍

[4,1,2,1,2] 的整体异或可以重排为 4^(1^1)^(2^2)，结果为 4。负数也按位运算，同样成立。

## 写代码时注意什么

此方法依赖“其他数恰好出现两次”，若出现三次不能直接套用。初值为 0，作为异或的单位元。

## 复杂度

- 时间：O(n)。
- 空间：O(1)。
