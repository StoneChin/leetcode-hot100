# 169. 多数元素

[力扣原题](https://leetcode.cn/problems/majority-element/) · 简单 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

题目保证存在出现次数超过一半的元素，找出它。

## 怎么想到这个方法

**Boyer–Moore 投票抵消**

维护候选 candidate 和票数 votes。票数为 0 时换当前数作为候选；相同数加一，不同数减一。这相当于每次删掉一对不同元素：多数元素比其他元素总数还多，所以无论怎样抵消，最终留下的候选一定是它。

## 跟着例子走一遍

[2,2,1,1,1,2,2] 的候选会经历票数升降甚至归零，但所有不同数配对抵消后，2 仍有剩余，最终候选为 2。

## 写代码时注意什么

若题目不保证多数元素存在，还要再遍历统计候选次数进行验证。本题已有保证，因此一趟足够；“最多”与“超过一半”不是同一条件。

## 复杂度

- 时间：O(n)。
- 空间：O(1)。
