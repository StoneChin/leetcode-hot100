# 31. 下一个排列

[力扣原题](https://leetcode.cn/problems/next-permutation/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

原地得到字典序恰好大一点的下一个排列，若已最大则变为最小排列。

## 怎么想到这个方法

**找右侧升序断点，交换后反转后缀**

从右向左找第一个 nums[i]<nums[i+1] 的位置。它后面的后缀已非递增，是这个前缀下最大的排列；想最小幅度增大整体，就必须增大 i。再从右向左找第一个大于 nums[i] 的数交换，它是可用的最小更大值。交换后后缀仍非递增，把后缀反转为升序，得到最小后续。

## 跟着例子走一遍

[1,3,2] 的断点在 1，从右找到 2 与其交换，得到 [2,3,1]，后缀反转为 [1,3]，最终 [2,1,3]。若输入 [3,2,1]，没有断点，整体反转。

## 写代码时注意什么

交换对象必须严格大于断点值，重复数字时尤其重要。后缀从 i+1 开始反转；若 i=-1，则恰好反转整个数组。

## 复杂度

- 时间：O(n)。
- 空间：O(1)。
