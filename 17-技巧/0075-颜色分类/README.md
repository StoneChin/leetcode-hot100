# 75. 颜色分类

[力扣原题](https://leetcode.cn/problems/sort-colors/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

原地把只含 0、1、2 的数组排序，不能直接调用排序函数。

## 怎么想到这个方法

**荷兰国旗三路划分**

用 low、i、high 划出四段：[0,low) 全为 0，[low,i) 全为 1，[i,high] 未处理，(high,n) 全为 2。遇 0 与 low 交换，low 与 i 都前进；遇 1 只移动 i；遇 2 与 high 交换，只减 high，因为换回 i 的元素还没检查。

## 跟着例子走一遍

[2,0,2,1,1,0] 先把首位 2 换到末尾，换回 0 后不能直接跳过；再次处理这个 0，再推进边界，最终为 [0,0,1,1,2,2]。

## 写代码时注意什么

处理 2 后不能 i++，否则会漏查换回的数。循环条件是 i<=high，最后一个未处理位置也要看。

## 复杂度

- 时间：O(n)。
- 空间：O(1)。
