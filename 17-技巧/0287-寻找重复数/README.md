# 287. 寻找重复数

[力扣原题](https://leetcode.cn/problems/find-the-duplicate-number/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

长度 n+1 的数组取值为 1..n，只有一种数重复，要求不修改数组、常数额外空间找出它。

## 怎么想到这个方法

**把数组看作带环链表**

把下标当节点，nums[i] 当作下一节点地址，即 i→nums[i]。从 0 出发，后继始终落在 1..n，有限节点必然形成环。0 不会被任何边指向，所以不在环内；路径首次进入环的节点有来自环外和环内的两个前驱，对应数组里两个相同值，也就是重复数。用快慢指针找相遇点，再从 0 与相遇点同步走到环入口。

## 跟着例子走一遍

[1,3,4,2,2] 形成 0→1→3→2→4→2，环入口为 2，恰好是重复值。算法沿数值跳转，不需要交换或标记数组。

## 写代码时注意什么

快指针走两步应写 nums[nums[fast]]。第二阶段一个指针回到下标 0，而不是 nums[0]，因为第一阶段也从 0 出发。此方法依赖值域 1..n。

## 复杂度

- 时间：O(n)。
- 空间：O(1)。
