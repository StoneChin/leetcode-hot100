# 438. 找到字符串中所有字母异位词

[力扣原题](https://leetcode.cn/problems/find-all-anagrams-in-a-string/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

找到 s 中所有与 p 互为字母异位词的子串起点。

## 怎么想到这个方法

**固定长度窗口 + 字母计数**

异位词只要求每种字母的出现次数相同，顺序无关。因此窗口长度固定为 p 的长度，并用两个长度为 26 的数组分别统计 p 和窗口。右端加入一个字符，若窗口超长，就从左端移走一个字符。当窗口够长且两个数组相等时，记录起点。

## 跟着例子走一遍

s = cbaebabacd，p = abc。第一个窗口 cba 的计数与 abc 相同，记录 0；继续滑动，直到下标 6 的 bac，再记录 6。每次只改移出和移入的两个字符。

## 写代码时注意什么

只有窗口长度等于 p 的长度时才比较。题目字符限定为小写英文字母，26 个计数足够；若 s 比 p 短，循环中不会记录任何答案。

## 复杂度

- 时间：O(26n)，即 O(n)。
- 空间：O(26)，不含输出。
