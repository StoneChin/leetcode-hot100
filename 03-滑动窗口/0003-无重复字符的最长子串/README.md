# 3. 无重复字符的最长子串

[力扣原题](https://leetcode.cn/problems/longest-substring-without-repeating-characters/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

求不含重复字符的最长连续子串长度。

## 怎么想到这个方法

**滑动窗口 + 最近出现位置**

窗口 [left,right] 始终不含重复字符。记录每个字符上一次出现的位置 last。读到当前字符时，如果它曾在窗口里出现，就把 left 移到那次出现的后一位；如果那次出现早已在窗口外，left 不动。每次扩展后，用窗口长度更新答案。

## 跟着例子走一遍

s = abba。读到第二个 b，left 从 0 移到 2，窗口只剩 b；最后读到 a，它上次出现于 0，已经在窗口外，left 仍为 2，窗口为 ba，最长长度为 2。

## 写代码时注意什么

left 必须取 max(left, last[c] + 1)，否则 abba 的最后一个 a 会让左边界倒退，重新把重复的 b 纳入窗口。字符转 unsigned char 后再用作数组下标。

## 复杂度

- 时间：O(n)。
- 空间：O(Σ)，本实现字符表为 256。
