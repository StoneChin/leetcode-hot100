# 本地验证

在项目根目录运行：

```bash
python3 scripts/check.py
```

脚本先检查 100 个不同题号、17 类题数、每题代码与解析是否齐全，以及 Markdown 本地链接是否有效。然后逐题生成独立测试程序，以 C++17 编译并运行。每个程序只引入一道题的代码，不会发生 `Solution` 重定义。

- `cases.json`：100 题的基本回归用例。除返回值外，还检查相交节点的地址、链表是否意外成环、回文链表与单词搜索是否恢复输入、建树的遍历结果及平衡性、缓存淘汰行为等。
- `exhaustive.json`：16 题的额外对照用例。穷举短数组或短字符串，用另一种直接方法计算期望值，比较实际结果。
- `support.hpp`：本地专用的节点定义、结构检查和释放函数。只有定义 `LOCAL_TEST` 时才会被解法引入，力扣提交无需此文件。

## 穷举范围

| 题号 | 输入范围 | 对照方式 |
| --- | --- | --- |
| 42、84 | 长度 0～7，值 0～3 | 逐位置找左右最高墙；枚举矩形区间 |
| 41 | 长度 0～6，值 -1～4 | 从 1 开始直接查找缺失值 |
| 560 | 长度 0～7，值 -1～1，k=-3～3 | 枚举所有非空子数组 |
| 152、53 | 长度 1～6，值 -2～2 | 枚举所有非空子数组 |
| 31 | 长度 0～7，值 0～2 | 对照标准库 `next_permutation` |
| 75 | 长度 0～8，值 0～2 | 对照标准库 `sort` |
| 239 | 长度 1～7，值 -1～1，所有合法 k | 每个窗口直接取最大值 |
| 300 | 长度 0～7，值 0～2 | 枚举所有子序列并检查严格递增 |
| 15 | 长度 0～6，值 -2～2 | 枚举所有不同下标三元组，并核对去重 |
| 198 | 长度 0～7，值 0～3 | 枚举所有不含相邻位的选择集合 |
| 416 | 长度 0～7，值 1～3 | 枚举全部子集求和 |
| 4 | 两数组各长 0～4，值 -1～1，总长非零 | 直接合并排序取中位数 |
| 32 | 长度 0～12 的全部括号字符串 | 枚举所有子串检查合法性 |
| 76 | 长度 0～7 的 a/b 字符串，7 种目标串 | 枚举所有子串检查覆盖次数及最短长度 |

少数穷举包含题目约束外的空数组，用于检查实现的自然边界行为，不表示原题允许空输入。检查通过仅代表这些本地用例通过，不代表已完成在线评测，也不能证明所有输入正确。
