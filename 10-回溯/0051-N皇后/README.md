# 51. N 皇后

[力扣原题](https://leetcode.cn/problems/n-queens/) · 困难 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

在 n×n 棋盘放 n 个互不攻击的皇后，返回所有布局。

## 怎么想到这个方法

**逐行放皇后，标记列与对角线**

每行恰好放一个皇后，因此逐行递归，当前行枚举列。用 col[c] 标记列占用，diag1[r-c+n-1] 标记同一条主对角线，diag2[r+c] 标记同一条副对角线。三种标记都为空才能放，递归下一行后撤销棋盘和标记。

## 跟着例子走一遍

n=4 的一种方案列号依次为 [1,3,0,2]。每行、每列各一枚皇后，任意两枚的 r-c 和 r+c 也都不同，因此没有对角攻击。

## 写代码时注意什么

r-c 可能为负，要加 n-1 再作下标。两类对角线数组长度都是 2n-1。放置与撤销必须同步修改三类标记和棋盘字符。

## 复杂度

- 时间：O(n·n! + S·n²) 宽松上界，S 为方案数。
- 空间：O(n²)，包含当前棋盘，不含输出。
