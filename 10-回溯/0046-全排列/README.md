# 46. 全排列

[力扣原题](https://leetcode.cn/problems/permutations/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

返回不含重复元素数组的所有排列。

## 怎么想到这个方法

**回溯枚举每个位置的选择**

path 保存当前排列前缀，used 标记哪些元素已经用过。每一层给下一个位置选择任意未使用元素：标记、加入、递归；返回后弹出并取消标记，让同层的其他选择使用干净状态。path 长度达到 n 时复制一份到结果。

## 跟着例子走一遍

[1,2,3] 先选 1，再选 2，最后选 3，得到 [1,2,3]；撤销最后两步，在 1 后选 3、2，得到 [1,3,2]，其他首元素同理。

## 写代码时注意什么

回溯不是全局永久访问，used 必须在返回后恢复。题目保证元素不同，所以按下标选择不会产生重复排列；若输入允许重复值，需要另加去重规则。

## 复杂度

- 时间：O(n·n!)，包含复制结果。
- 空间：O(n) 辅助空间，不含输出。
