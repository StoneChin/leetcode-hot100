# 22. 括号生成

[力扣原题](https://leetcode.cn/problems/generate-parentheses/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

生成 n 对括号组成的所有合法字符串。

## 怎么想到这个方法

**只生成合法前缀**

left、right 表示已放的左右括号数量。只要 left<n 就能放左括号；只有 right<left 时才能放右括号，保证任意前缀都不会右括号过多。长度达到 2n 时记录答案。这样在生成过程中就排除非法分支，不需要先生成全部字符串再检查。

## 跟着例子走一遍

n=2，开头只能是 (。第二位选 ( 后只能继续补 ))，得到 (())；第二位选 ) 后再补 ()，得到 ()()。

## 写代码时注意什么

right<n 并不足以保证合法，必须 right<left。回溯每次撤销刚加入的字符；结果数量是第 n 个卡特兰数。

## 复杂度

- 时间：O(n·Cₙ)，Cₙ 为第 n 个卡特兰数。
- 空间：O(n)，不含输出。
