# 78. 子集

[力扣原题](https://leetcode.cn/problems/subsets/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

返回数组的所有子集，包括空集和整个数组。

## 怎么想到这个方法

**每个数选或不选**

处理到下标 i 时，先递归不选 nums[i] 的分支，再把它放入 path，递归选择它的分支，最后撤销。到数组末尾时，一条完整的选择路径就对应一个子集。每个元素只有选与不选两种状态，因此恰好有 2^n 个子集。

## 跟着例子走一遍

[1,2] 的选择路径依次为都不选、只选 2、只选 1、两个都选，得到 []、[2]、[1]、[1,2]。结果顺序不限。

## 写代码时注意什么

空集也要保存。只在 i==n 时记录一次，避免同一条路径被多次记录。题目元素互不相同，因此不同选择路径不会得到重复子集。

## 复杂度

- 时间：O(n·2^n)，包含结果复制。
- 空间：O(n)，不含输出。
