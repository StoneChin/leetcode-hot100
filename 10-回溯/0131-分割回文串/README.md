# 131. 分割回文串

[力扣原题](https://leetcode.cn/problems/palindrome-partitioning/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

把字符串切成若干非空回文串，返回所有切法。

## 怎么想到这个方法

**预处理回文区间 + 枚举切分点**

先用 pal[l][r] 记录 s[l..r] 是否回文：两端相等，且中间也是回文，就成立；长度为 1、2 时直接由两端决定。再从 start 枚举本段结束位置 end，只有 pal[start][end] 为真才选这一段并递归后面。start 到末尾时记录完整划分。

## 跟着例子走一遍

s = aab。从 0 开始可以选 a，后面再切 a、b，得到 [a,a,b]；也可以先选 aa，再选 b，得到 [aa,b]。aab 自己不是回文，不会被选。

## 写代码时注意什么

预处理时 l 从右向左走，确保 pal[l+1][r-1] 已经算好。子串长度是 end-start+1，不能漏掉末尾字符；回溯后撤销刚选的那一段。

## 复杂度

- 时间：O(n²+n·2^n)，包含切分输出。
- 空间：O(n²)，不含输出。
