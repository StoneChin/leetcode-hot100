# 39. 组合总和

[力扣原题](https://leetcode.cn/problems/combination-sum/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

用互不相同的正整数拼出 target，每个数可重复使用，组合不可重复。

## 怎么想到这个方法

**固定候选起点，允许重复选当前数**

排序后，用 start 限制下一步只能选当前及后面的候选，保证 path 非递减，消除同一组合的不同排列。选 candidates[i] 后，递归仍从 i 开始，因为它可重复使用；剩余和为 0 时记录答案。候选超过剩余和就停止本层，后面更大的数也不用试。

## 跟着例子走一遍

candidates = [2,3,6,7]，target=7。选择 2 后还能继续选 2，再选 3，得到 [2,2,3]；另一路直接选 7。不会额外生成 [3,2,2]。

## 写代码时注意什么

这里递归传 i，而不是 i+1；后者会禁止重复使用。同一组合内部按候选顺序走，才能避免排列重复。剪枝依赖全部候选为正数。

## 复杂度

- 时间：O(N^D·D) 宽松上界，D=⌊target/min⌋，N 为候选数。
- 空间：O(D)，不含输出。
