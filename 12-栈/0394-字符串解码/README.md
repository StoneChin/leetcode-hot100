# 394. 字符串解码

[力扣原题](https://leetcode.cn/problems/decode-string/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

解码形如 k[内容] 的嵌套字符串。

## 怎么想到这个方法

**栈保存外层字符串与重复次数**

用 number 累积可能有多位的次数，用 cur 构建当前层的字符串。遇到 [，把外层 cur 和次数压栈，清空当前层；遇到 ]，当前层已经解码完成，弹出外层，将 cur 重复指定次数拼到外层之后。普通字母直接追加。

## 跟着例子走一遍

3[a2[c]]：进入内层后得到 c，关闭内层时变成 acc；关闭外层时把 acc 重复三次，得到 accaccacc。

## 写代码时注意什么

number 按 number*10+当前数字累积，不能只取一位。每次进入新层必须清零次数并清空 cur。输出可能远大于输入，复杂度应考虑实际展开和拼接量。

## 复杂度

- 时间：O(L·d) 保守上界，L 为解码后长度，d 为最大嵌套深度。
- 空间：O(L+|s|)。
