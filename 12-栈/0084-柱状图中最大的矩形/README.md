# 84. 柱状图中最大的矩形

[力扣原题](https://leetcode.cn/problems/largest-rectangle-in-histogram/) · 困难 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

在柱状图中找面积最大的轴对齐矩形。

## 怎么想到这个方法

**递增栈确定矩形左右边界**

栈保存高度非递减的柱子下标。遇到更矮柱子时，栈顶柱子无法继续向右延伸，弹出它并以它的高度结算面积：右界是当前下标之前，左界是弹出后新栈顶之后，所以宽度为 i-left-1。末尾虚拟补一根高度 0 的柱子，把还没结算的柱子一起清理。

## 跟着例子走一遍

[2,1,5,6,2,3] 在下标 4 遇到高度 2，先弹出 6 算面积 6，再弹出 5，它能横跨下标 2、3，面积为 10。

## 写代码时注意什么

弹出后再取左边界，栈空则 left=-1。相同高度本实现保留，较右者先结算较窄区域，较左者之后仍能覆盖完整宽度，不会漏掉最大面积。

## 复杂度

- 时间：O(n)。
- 空间：O(n)。
