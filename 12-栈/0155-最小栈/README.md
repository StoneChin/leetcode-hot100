# 155. 最小栈

[力扣原题](https://leetcode.cn/problems/min-stack/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

实现支持 push、pop、top、getMin 且操作都为 O(1) 的栈。

## 怎么想到这个方法

**每层同时保存当前最小值**

栈里每项保存二元组：本次压入的值，以及从栈底到这一层的最小值。压入 x 时，新最小值为 x 与旧最小值的较小者；弹出时这层记录一起消失，下面一层已经保存好恢复后的最小值。

## 跟着例子走一遍

依次压入 -2、0、-3，记录的最小值分别是 -2、-2、-3。弹出 -3 后，栈顶的最小值记录自动恢复为 -2。

## 写代码时注意什么

不能只用一个全局最小值，因为弹出当前最小元素后无法恢复旧答案。题目保证 pop、top、getMin 都只在非空栈调用。

## 复杂度

- 时间：所有操作 O(1)。
- 空间：O(n)。
