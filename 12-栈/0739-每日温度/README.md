# 739. 每日温度

[力扣原题](https://leetcode.cn/problems/daily-temperatures/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

对每一天，求需要等待多少天才会出现更高温度。

## 怎么想到这个方法

**单调栈保存还没等到升温的日期**

栈中存日期下标，对应温度从底到顶非递增。新温度比栈顶高时，今天就是栈顶日期第一次遇到的更暖日子，弹出并填写下标差；继续处理可能也被今天解决的更早日期。最后把今天入栈，没被解决的日期默认答案为 0。

## 跟着例子走一遍

[73,74,75,71,69,72,76,73] 中，第 5 天的 72 会解决第 4 天的 69 和第 3 天的 71，等待分别为 1 和 2。

## 写代码时注意什么

题目要求严格更高，温度相等不能出栈。栈保存下标而不是温度，才能算等待天数。每个下标只进出一次。

## 复杂度

- 时间：O(n)。
- 空间：O(n)，不含输出。
