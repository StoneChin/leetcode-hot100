# 20. 有效的括号

[力扣原题](https://leetcode.cn/problems/valid-parentheses/) · 简单 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

判断括号字符串是否种类对应且嵌套合法。

## 怎么想到这个方法

**栈保存尚未匹配的左括号**

遇到左括号就压栈；遇到右括号时，最近出现但尚未闭合的左括号必须与它配对，所以检查栈顶。匹配就弹出，不匹配或栈为空就失败。扫描完还要求栈为空，表示没有遗留左括号。

## 跟着例子走一遍

([]) 的栈变化为 (、([、(、空，所以合法。([)] 遇到 ) 时，栈顶却是 [，立即失败。

## 写代码时注意什么

括号数量相等不代表嵌套合法。每次访问 top 前都要检查 empty；结束时也不能只看有没有发生过不匹配，还要检查残留。

## 复杂度

- 时间：O(n)。
- 空间：O(n)。
