# 48. 旋转图像

[力扣原题](https://leetcode.cn/problems/rotate-image/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

原地将 n×n 矩阵顺时针旋转 90 度。

## 怎么想到这个方法

**转置后反转每一行**

顺时针旋转要求原位置 (i,j) 变成 (j,n-1-i)。先沿主对角线转置，把 (i,j) 变为 (j,i)；再反转每一行，把列号 i 变为 n-1-i。两个操作合起来恰好得到目标位置，而且都可以原地完成。

## 跟着例子走一遍

[[1,2],[3,4]] 转置后为 [[1,3],[2,4]]，每行反转后为 [[3,1],[4,2]]。原来的左下角 3 被移到了左上角。

## 写代码时注意什么

转置只交换主对角线一侧的元素，例如 j > i。若两侧都交换，每对元素会被交换两次，等于没有转置。题目限定为方阵。

## 复杂度

- 时间：O(n²)。
- 空间：O(1)。
