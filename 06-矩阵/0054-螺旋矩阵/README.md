# 54. 螺旋矩阵

[力扣原题](https://leetcode.cn/problems/spiral-matrix/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

按顺时针螺旋顺序访问矩阵的所有元素。

## 怎么想到这个方法

**四条边界逐层收缩**

用 top、bottom、left、right 围住还没访问的矩形。依次走上边、右边、下边、左边，每走完一条边就收缩对应边界。走下边、左边前再次确认对应方向还有元素，防止剩下一行或一列时重复访问。

## 跟着例子走一遍

3×3 矩阵 [[1,2,3],[4,5,6],[7,8,9]] 先走外圈 1,2,3,6,9,8,7,4，边界收缩后只剩中心 5。

## 写代码时注意什么

单行和单列是最容易重复访问的情况。上边和右边走完后，必须重新判断 top <= bottom、left <= right，不能只依赖最外层 while 的条件。

## 复杂度

- 时间：O(mn)。
- 空间：O(1)，不含输出。
