# 73. 矩阵置零

[力扣原题](https://leetcode.cn/problems/set-matrix-zeroes/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

若某个元素为 0，将它所在整行和整列置零。

## 怎么想到这个方法

**首行首列充当标记**

先单独记录首行、首列原本有没有零。随后只扫描内部区域，发现 matrix[i][j] 为 0，就把 matrix[i][0] 和 matrix[0][j] 设为 0，作为这一行、这一列需要清零的标记。再根据标记清理内部，最后按最初的两个布尔值处理首行、首列。

## 跟着例子走一遍

[[1,1,1],[1,0,1],[1,1,1]] 的中心为零，于是首列下标 1 和首行下标 1 被标记。第二趟将中间行和中间列清零，四个角仍为 1。

## 写代码时注意什么

不能一发现零就清整行，否则新写的零会继续影响其他行。首行首列兼任标记，必须保存它们原本的状态，并最后再处理。

## 复杂度

- 时间：O(mn)。
- 空间：O(1)。
