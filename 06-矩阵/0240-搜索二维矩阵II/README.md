# 240. 搜索二维矩阵 II

[力扣原题](https://leetcode.cn/problems/search-a-2d-matrix-ii/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

在每行递增、每列递增的矩阵中查找 target。

## 怎么想到这个方法

**从右上角逐行逐列排除**

右上角有一个好处：往左变小，往下变大。如果当前值比目标大，它所在列从当前位置往下只会更大，整列可以排除，左移；如果当前值比目标小，它所在行向左只会更小，整行可以排除，下移。每一步都能排除一整行或一整列。

## 跟着例子走一遍

矩阵 [[1,4,7],[2,5,8],[3,6,9]] 查 6，从 7 左移到 4，再下移到 5、6，命中目标。

## 写代码时注意什么

不能把这道题的矩阵直接展开做普通二分：下一行第一个数不一定大于上一行最后一个数。右上角或左下角都可用，左上角不能据此唯一决定方向。

## 复杂度

- 时间：O(m+n)。
- 空间：O(1)。
