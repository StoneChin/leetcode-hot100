# 72. 编辑距离

[力扣原题](https://leetcode.cn/problems/edit-distance/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

允许插入、删除、替换一个字符，求把 word1 变成 word2 的最少操作数。

## 怎么想到这个方法

**前缀编辑距离**

dp[i][j] 表示 word1 前 i 个字符变成 word2 前 j 个字符的最少次数。末尾相同就沿用 dp[i-1][j-1]；末尾不同时，删除来自 dp[i-1][j]+1，插入来自 dp[i][j-1]+1，替换来自 dp[i-1][j-1]+1，三者取最小。空串变目标要插入 j 次，源串变空要删除 i 次。

## 跟着例子走一遍

horse 变 ros 可以先把 h 替换为 r 得到 rorse，再删除多余的 r 得到 rose，最后删除 e 得到 ros，共 3 次。

## 写代码时注意什么

插入状态 dp[i][j-1] 表示先得到目标前 j-1 个字符，再补最后一个字符，不是跳过源字符。初始化首行首列是必要的，不能全留为 0。

## 复杂度

- 时间：O(mn)。
- 空间：O(mn)。
