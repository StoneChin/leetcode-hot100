# 5. 最长回文子串

[力扣原题](https://leetcode.cn/problems/longest-palindromic-substring/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

返回最长的连续回文子串，存在多个答案时任选一个。

## 怎么想到这个方法

**枚举奇偶两类回文中心**

回文两端对称，可以枚举中心并向两边扩张。奇数长度以某个字符为中心，初始 l=r=i；偶数长度以两个字符的缝为中心，初始 l=i、r=i+1。只要两端相等就继续外扩，退出时实际回文范围为 [l+1,r)，用它更新最佳起点和长度。

## 跟着例子走一遍

babad 在下标 1 的 a 周围扩张得到 bab，长度 3；在下标 2 的 b 周围得到 aba，也长 3。cbbd 则必须考虑两个 b 中间的偶数中心，才能找到 bb。

## 写代码时注意什么

只枚举单字符中心会漏掉所有偶数回文。循环退出后的 l、r 已经越过有效范围，长度应为 r-l-1，起点为 l+1。

## 复杂度

- 时间：O(n²)。
- 空间：O(1)，不含返回字符串。
