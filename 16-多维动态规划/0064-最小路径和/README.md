# 64. 最小路径和

[力扣原题](https://leetcode.cn/problems/minimum-path-sum/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

从网格左上走到右下，只能向右或向下，求沿途数字和的最小值。

## 怎么想到这个方法

**按行滚动计算最小代价**

dp[j] 表示到当前行第 j 列的最小代价。到内部格子时，从上方 dp[j] 与左方 dp[j-1] 取较小值，再加当前格。起点单独赋值；首行只能从左来，首列只能从上来，分别处理。这样无需无穷大哨兵，也不改变输入。

## 跟着例子走一遍

[[1,3,1],[1,5,1],[4,2,1]] 的最优路径为 1→3→1→1→1，总和 7。每次只保留到当前列的最低成本。

## 写代码时注意什么

当前格的数必须计入，包括起点和终点。首行首列的来源不同，不能不加判断就访问 dp[j-1]。

## 复杂度

- 时间：O(mn)。
- 空间：O(n)。
