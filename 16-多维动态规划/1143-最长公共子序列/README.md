# 1143. 最长公共子序列

[力扣原题](https://leetcode.cn/problems/longest-common-subsequence/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

求两个字符串最长公共子序列的长度，字符可不连续但顺序不变。

## 怎么想到这个方法

**两段前缀的最长公共子序列**

dp[i][j] 表示 text1 前 i 个字符与 text2 前 j 个字符的最长公共子序列长度。末尾字符相等，就在两个更短前缀的答案上加 1；不相等，就至少要舍弃一个末尾字符，取 dp[i-1][j] 与 dp[i][j-1] 的最大值。空前缀的答案为 0。

## 跟着例子走一遍

abcde 与 ace：a、c、e 可以依次对应，虽然在第一个串里不连续，但顺序一致，长度为 3。末尾 e 相等时，答案来自 abcd 与 ac 的答案 2 再加 1。

## 写代码时注意什么

子序列不同于子串，不相等时不能把状态清零。表多开一行一列处理空前缀，字符串下标始终比状态下标少 1。

## 复杂度

- 时间：O(mn)。
- 空间：O(mn)。
