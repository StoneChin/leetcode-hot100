# 62. 不同路径

[力扣原题](https://leetcode.cn/problems/unique-paths/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

机器人从左上走到右下，只能向右或向下，求不同路径数。

## 怎么想到这个方法

**按行滚动计算路径数**

到格子 (i,j) 的最后一步只能来自上方或左方，所以路径数是两者之和。一维 dp[j] 在更新前代表上方，dp[j-1] 已经更新为本行左方，直接 dp[j]+=dp[j-1]。首行与首列都只有一种走法，初始化为 1。

## 跟着例子走一遍

3×3 网格首行为 [1,1,1]，第二行更新为 [1,2,3]，第三行为 [1,3,6]，右下角有 6 条路径。

## 写代码时注意什么

内层从左向右更新，才能拿到本行左边的新状态。第一列始终为 1，不需更新。题目保证 m、n 为正且答案在 int 范围内。

## 复杂度

- 时间：O(mn)。
- 空间：O(n)。
