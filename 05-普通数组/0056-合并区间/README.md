# 56. 合并区间

[力扣原题](https://leetcode.cn/problems/merge-intervals/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

合并所有有重叠的区间。

## 怎么想到这个方法

**按左端点排序后合并**

排序后，区间按左端点从小到大出现。只需要看当前区间与结果的最后一个区间：若当前左端点超过最后区间的右端点，两者分开，追加新区间；否则有重叠，把最后区间的右端点扩展到两者右端点的最大值。更早的结果区间已经结束，不可能再与当前区间合并。

## 跟着例子走一遍

[[1,3],[2,6],[8,10],[15,18]] 中，第二段起点 2 不超过 3，前两段合并成 [1,6]；8 超过 6，另开一段。

## 写代码时注意什么

[1,4] 和 [4,5] 也算重叠，所以分开的判断是 >，不能用 >=。合并时取右端点的最大值，避免被完全包含的短区间缩小边界。

## 复杂度

- 时间：O(n log n)。
- 空间：O(log n) 排序栈，不含输出。
