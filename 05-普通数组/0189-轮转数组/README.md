# 189. 轮转数组

[力扣原题](https://leetcode.cn/problems/rotate-array/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

原地将数组向右轮转 k 个位置。

## 怎么想到这个方法

**三次反转**

右移 k 位相当于把最后 k 个元素搬到前面，同时保持两段各自的顺序。先整体反转，两段就交换了位置，但段内顺序也反了；再分别反转前 k 个元素和剩余元素，就恢复了各段内部的顺序。先对 k 取模，因为移动 n 位等于没有移动。

## 跟着例子走一遍

[1,2,3,4,5,6,7] 右移 3 位：整体反转得到 [7,6,5,4,3,2,1]，前 3 位反转为 [5,6,7]，后 4 位反转为 [1,2,3,4]。

## 写代码时注意什么

先处理空数组，再做 k %= n，避免除以 0。分界点是 begin() + k，reverse 的右边界不包含在区间内。

## 复杂度

- 时间：O(n)。
- 空间：O(1)。
