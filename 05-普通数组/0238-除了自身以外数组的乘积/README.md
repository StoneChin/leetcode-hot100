# 238. 除了自身以外数组的乘积

[力扣原题](https://leetcode.cn/problems/product-of-array-except-self/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

不使用除法，求每个位置以外的所有元素的乘积。

## 怎么想到这个方法

**左右乘积分两趟计算**

当前位置的答案等于左边所有数的乘积乘以右边所有数的乘积。第一趟从左向右，把左边乘积写进 ans[i]，然后才把 nums[i] 乘入累计值。第二趟从右向左维护右边乘积，并乘到 ans[i] 上。输出数组兼任左乘积存储，不需要额外开两张表。

## 跟着例子走一遍

[1,2,3,4] 第一趟得到 [1,1,2,6]，右边乘积依次为 1、4、12、24，最终结果是 [24,12,8,6]。

## 写代码时注意什么

更新顺序不能反过来，否则会把自己乘进去。边界外的空乘积设为 1；有零时流程仍然成立，比用总乘积除以当前数更稳妥。

## 复杂度

- 时间：O(n)。
- 空间：O(1) 额外空间，不含输出。
