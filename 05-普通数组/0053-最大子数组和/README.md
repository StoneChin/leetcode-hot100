# 53. 最大子数组和

[力扣原题](https://leetcode.cn/problems/maximum-subarray/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

找出和最大的非空连续子数组，返回它的和。

## 怎么想到这个方法

**以当前位置结尾的最优和**

end 表示必须以当前元素结尾的最大子数组和。来到 x 时，只有两种选择：接在前一段后面，得到 end + x；或者丢掉前一段，从 x 重新开始。取两者较大值，再用它更新全局答案。前一段为负数时，接上它只会拖累当前元素。

## 跟着例子走一遍

[-2,1,-3,4,-1,2,1,-5,4] 中，走到 4 时前面的结尾和为负，于是从 4 重开；接上 -1、2、1 后达到 6，对应 [4,-1,2,1]。

## 写代码时注意什么

初值必须来自第一个元素，不能把答案设为 0，否则全负数组会错误地选到空子数组。题目保证数组非空。

## 复杂度

- 时间：O(n)。
- 空间：O(1)。
