# 41. 缺失的第一个正数

[力扣原题](https://leetcode.cn/problems/first-missing-positive/) · 困难 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

在线性时间、常数额外空间内，找最小的缺失正整数。

## 怎么想到这个方法

**原地把正数放回对应位置**

长度为 n 的数组，答案只可能在 1 到 n + 1 之间。把数组看成 n 个编号槽位：数值 x 应放在下标 x - 1。扫描每个位置，只要当前数在 1 到 n 范围内、目标位置也不是同一个数，就交换过去，并继续检查换回来的数。全部归位后，第一个 nums[i] 不等于 i + 1 的位置就是答案。

## 跟着例子走一遍

[3,4,-1,1] 归位后可得到 [1,-1,3,4]。下标 0 正确，下标 1 不是 2，所以最小缺失正数为 2。负数和超过 n 的数不需要安排位置。

## 写代码时注意什么

交换前必须检查目标位置是否已有相同数，否则 [1,1] 会一直交换。虽然有 while，每次成功交换至少让一个合法数归位，总交换次数不超过线性量级。会修改输入数组。

## 复杂度

- 时间：O(n)。
- 空间：O(1)。
