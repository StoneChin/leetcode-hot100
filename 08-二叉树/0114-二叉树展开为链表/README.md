# 114. 二叉树展开为链表

[力扣原题](https://leetcode.cn/problems/flatten-binary-tree-to-linked-list/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

原地把二叉树展开成只沿 right 连接的前序链，所有 left 为空。

## 怎么想到这个方法

**把左子树插入根与右子树之间**

若当前节点有左子树，找到左子树沿 right 走到的最右节点，将原右子树接到它的 right；再把整棵左子树搬到当前节点 right，并清空 left。这样顺序变成根、原左子树、原右子树。继续沿 right 处理，最终所有节点串成前序链。

## 跟着例子走一遍

1 的左孩子为 2，右孩子为 5，2 的右孩子为 3。先把 5 接到 3 后面，再让 1.right 指向 2；得到 1→2→3→5 的主链，后续继续处理残留左子树。

## 写代码时注意什么

寻找的是沿 right 链的末端，不是按节点值找最大值。重连前先保留原右子树的入口；left 必须置空。找前驱时所经过的右边只被摊还访问常数次，总体线性。

## 复杂度

- 时间：O(n)。
- 空间：O(1)。
