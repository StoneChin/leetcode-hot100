# 236. 二叉树的最近公共祖先

[力扣原题](https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-tree/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

找到二叉树中 p、q 的最近公共祖先，节点可以是自身的祖先。

## 怎么想到这个方法

**后序递归汇合两个目标**

当前节点为空就返回空，等于 p 或 q 就返回自己。否则分别查左右子树：两边都找到目标，说明 p、q 在当前节点两侧，当前节点就是最近公共祖先；只有一边找到，就把那一边的结果上传。题目保证两个目标都在树中，因此一个目标在另一个目标的子树内时，返回上面的目标也正确。

## 跟着例子走一遍

根 3 的左边有 p=5，右边有 q=1，左右递归都返回非空，答案为 3。若 q 在 5 的子树里，答案则是 5。

## 写代码时注意什么

比较节点地址而不是值。此代码采用题目中目标必定存在的条件；若允许缺失目标，还需要额外验证两者是否都出现。

## 复杂度

- 时间：O(n)。
- 空间：O(h)。
