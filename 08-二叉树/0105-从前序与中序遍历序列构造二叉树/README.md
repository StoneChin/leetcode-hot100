# 105. 从前序与中序遍历序列构造二叉树

[力扣原题](https://leetcode.cn/problems/construct-binary-tree-from-preorder-and-inorder-traversal/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

由前序和中序遍历恢复节点值互不相同的二叉树。

## 怎么想到这个方法

**前序定根，中序划分左右区间**

前序的第一个未用元素是当前根，在中序数组找到它，就能分出左、右子树。用哈希表预存值在中序中的下标，避免每次线性搜索。递归处理左区间，再处理右区间，同时前序游标持续向后，正好对应根、左、右的读取顺序。

## 跟着例子走一遍

前序 [3,9,20,15,7]，中序 [9,3,15,20,7]。根是 3，中序左边只有 9，右边为 [15,20,7]；下一棵右子树的根是前序里的 20。

## 写代码时注意什么

先建左子树再建右子树，顺序要和前序一致。题目保证遍历合法且值不重复；重复值无法用一个下标表确定唯一划分。每次公开调用重置游标。

## 复杂度

- 时间：平均 O(n)。
- 空间：O(n)，不含新树。
