# 108. 将有序数组转换为二叉搜索树

[力扣原题](https://leetcode.cn/problems/convert-sorted-array-to-binary-search-tree/) · 简单 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

把升序数组构造成高度平衡的二叉搜索树。

## 怎么想到这个方法

**中点作根，递归处理两边**

数组中点的左边都更小，右边都更大，所以选中点为根天然符合搜索树条件。左右区间再各自选中点建子树，区间大小始终接近一半，树高也就保持平衡。使用左闭右开区间 [l,r)，空区间 l>=r 返回空。

## 跟着例子走一遍

[-10,-3,0,5,9] 选 0 为根，[-10,-3] 建左子树，[5,9] 建右子树。偶数长度有两个中间候选，选其中任一个都能得到合法答案。

## 写代码时注意什么

答案不唯一，不应只按某一张树的形状判断正确性。测试更应检查中序遍历是否等于原数组、各节点是否平衡。返回节点由调用者管理。

## 复杂度

- 时间：O(n)。
- 空间：O(log n) 递归栈，不含新树。
