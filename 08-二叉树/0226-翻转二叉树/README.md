# 226. 翻转二叉树

[力扣原题](https://leetcode.cn/problems/invert-binary-tree/) · 简单 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

将二叉树左右镜像翻转。

## 怎么想到这个方法

**递归交换左右子树**

每个节点需要做同一件事：交换左、右孩子，再让两个子树各自完成翻转。根上的交换决定大方向，递归保证子树内部也全部镜像。空节点无需处理，最终仍返回原根地址。

## 跟着例子走一遍

根 4 的孩子是 2、7，交换后为 7、2；原来 2 下的 1、3 也交换为 3、1。不能只交换根的两个孩子。

## 写代码时注意什么

本算法直接修改原树。交换后递归当前的左右孩子即可，两棵子树都会被访问一次，不会因为换过位置而遗漏。

## 复杂度

- 时间：O(n)。
- 空间：O(h)。
