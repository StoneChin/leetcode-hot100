# 230. 二叉搜索树中第 K 小的元素

[力扣原题](https://leetcode.cn/problems/kth-smallest-element-in-a-bst/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

在二叉搜索树中找到第 k 小的节点值。

## 怎么想到这个方法

**中序遍历数到第 k 个**

搜索树的中序遍历就是升序序列。用栈进行中序遍历，每弹出一个节点，说明访问了下一个最小值，让 k 减一；减到 0 时立即返回，无需遍历剩余节点。

## 跟着例子走一遍

根 3，左子树为 1→右孩子 2，右孩子为 4。中序序列为 1,2,3,4，k=2 时弹出 2 即可返回。

## 写代码时注意什么

题目保证 1<=k<=节点数。k 统计的是实际访问节点的次数，压栈只是准备工作，不能在压栈时减 k。

## 复杂度

- 时间：O(h+k)，最坏 O(n)。
- 空间：O(h)。
