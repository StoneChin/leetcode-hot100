# 543. 二叉树的直径

[力扣原题](https://leetcode.cn/problems/diameter-of-binary-tree/) · 简单 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

求任意两节点之间最长路径的边数，路径不必经过根。

## 怎么想到这个方法

**求高度时顺便更新直径**

递归返回当前子树的高度，按节点数计算。某节点左、右子树高度为 l、r，经过这个节点的最长路径边数恰好为 l+r。每次用它更新全局直径，同时向父节点只返回 1+max(l,r)，因为父节点只能沿其中一条分支继续。

## 跟着例子走一遍

根的左右子树高度分别为 2 和 1，穿过根的路径有 3 条边。若更长的路径完全位于某棵子树，它也会在递归处理对应转折点时更新到答案。

## 写代码时注意什么

区分递归返回的高度与最终直径：高度按节点计，直径按边计。空树和单节点直径均为 0；每次调用清空成员答案。

## 复杂度

- 时间：O(n)。
- 空间：O(h)。
