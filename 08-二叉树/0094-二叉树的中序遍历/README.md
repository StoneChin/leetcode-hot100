# 94. 二叉树的中序遍历

[力扣原题](https://leetcode.cn/problems/binary-tree-inorder-traversal/) · 简单 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

按左子树、根节点、右子树的顺序返回节点值。

## 怎么想到这个方法

**显式栈模拟中序遍历**

沿左孩子不断向下，把沿途节点压栈。走到空节点时弹出栈顶，它的左子树已经访问完，可以记录它；随后转向它的右子树，再重复同样过程。栈保存的是“左边处理完后，还要回来访问”的祖先。

## 跟着例子走一遍

树 2 的左孩子为 1、右孩子为 3。先压入 2、1，弹出 1，再弹出 2，然后进入右边的 3，结果为 [1,2,3]。

## 写代码时注意什么

外层循环要用 cur 非空或栈非空。只检查 cur 会在第一次走到最左侧空节点时提前结束。空树自然返回空数组。

## 复杂度

- 时间：O(n)。
- 空间：O(h)，h 为树高。
