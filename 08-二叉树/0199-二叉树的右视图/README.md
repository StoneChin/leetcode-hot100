# 199. 二叉树的右视图

[力扣原题](https://leetcode.cn/problems/binary-tree-right-side-view/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

从树右侧观察，返回每层能看到的节点值。

## 怎么想到这个方法

**层序遍历取最后一个节点**

队列按从左到右的顺序逐层遍历。在每一层中，最后弹出的节点就是这一层最右边的节点，记录它即可。右视图不等于一直沿右孩子走：右子树较短时，左子树深处的节点也可能露出来。

## 跟着例子走一遍

根 1，左孩子 2，右孩子 3，2 下还有孩子 4。每层最后节点分别为 1、3、4，因此右视图为 [1,3,4]。

## 写代码时注意什么

孩子入队顺序要先左后右，本轮最后一个才代表最右边。每层开始保存队列大小，别把下一层混入当前层。

## 复杂度

- 时间：O(n)。
- 空间：O(w)。
