# 124. 二叉树中的最大路径和

[力扣原题](https://leetcode.cn/problems/binary-tree-maximum-path-sum/) · 困难 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

求任意非空路径的最大节点值之和，路径不能重复节点。

## 怎么想到这个方法

**单边贡献上传，双边路径更新答案**

递归返回从当前节点出发向下走一条分支的最大贡献。左右贡献若为负，就取 0，相当于不走这边。用 当前值+左贡献+右贡献 更新全局答案，这是一条在当前节点转弯的完整路径；但返回给父节点时只能选左右较大的一边，否则父节点接上来会产生分叉。

## 跟着例子走一遍

[-10,9,20,空,空,15,7] 中，20 处合并左右贡献得到 15+20+7=42。上传给 -10 的却只能是 20+max(15,7)=35，最终最大路径仍为 42。

## 写代码时注意什么

全局答案初始化为 INT_MIN，不能为 0，因为路径必须非空，全负树也要选一个节点。返回值和全局答案扮演不同角色，不要把双边路径继续上传。

## 复杂度

- 时间：O(n)。
- 空间：O(h)。
