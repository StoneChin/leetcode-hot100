# 101. 对称二叉树

[力扣原题](https://leetcode.cn/problems/symmetric-tree/) · 简单 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

判断二叉树是否关于根节点左右对称。

## 怎么想到这个方法

**成对比较镜像位置**

定义 mirror(a,b) 判断两棵子树是否互为镜像。两者都空为真，只有一个空为假；节点值也必须相等。之后比较 a 的左边与 b 的右边、a 的右边与 b 的左边。对称要求结构和数值同时匹配。

## 跟着例子走一遍

根下两个值为 2 的节点，左边的外侧孩子为 3，右边的外侧孩子也为 3，它们应配对比较；不能把两边的左孩子直接配对。

## 写代码时注意什么

只比较每层数值是否回文不够：若不保留空位置，会把不同结构误判成对称。递归按镜像位置比较能自然处理空位。

## 复杂度

- 时间：O(n)。
- 空间：O(h)。
