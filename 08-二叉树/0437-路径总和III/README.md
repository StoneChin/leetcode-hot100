# 437. 路径总和 III

[力扣原题](https://leetcode.cn/problems/path-sum-iii/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

统计沿父到子方向、节点值和等于 targetSum 的路径数量，起点终点任意。

## 怎么想到这个方法

**树上的前缀和 + 回溯计数**

沿根到当前节点维护前缀和 sum。若祖先路径上的某个前缀为 sum-target，就得到一条以当前节点结尾的合法路径。哈希表只保存当前根路径的前缀次数，进入节点时先查询、再登记；离开节点时撤销登记，防止左子树的前缀被右子树误用。

## 跟着例子走一遍

一条向下路径值为 [1,-1,1]，目标为 1。当前前缀到最后为 1，路径上前缀 0 出现两次，因此有两条以最后节点结尾的路径：最后的 1，以及整个 [1,-1,1]。

## 写代码时注意什么

前缀和用 long long，深路径累计可能超过 int。退出节点时必须减回次数；树上前缀只允许来自当前祖先链，不能像数组一样一直保留所有已访问节点。

## 复杂度

- 时间：平均 O(n)。
- 空间：O(n)，包含计数表和 O(h) 栈。
