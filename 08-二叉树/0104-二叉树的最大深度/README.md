# 104. 二叉树的最大深度

[力扣原题](https://leetcode.cn/problems/maximum-depth-of-binary-tree/) · 简单 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

返回从根到最远叶子的节点数。

## 怎么想到这个方法

**递归求左右子树高度**

空树深度为 0。非空树的最深路径一定进入左子树或右子树，所以先分别求出两边深度，取较大者再加上根节点这一层。这个递归的返回值就是当前子树的深度，不需要额外记录全局层数。

## 跟着例子走一遍

根节点有左叶子，右边还有两层，左右深度分别为 1、2，整棵树深度为 max(1,2)+1=3。

## 写代码时注意什么

题目按节点数计深度，单节点树为 1。退化为链表的树会产生 O(n) 层递归；本实现适用于题目的规模。

## 复杂度

- 时间：O(n)。
- 空间：O(h) 递归栈。
