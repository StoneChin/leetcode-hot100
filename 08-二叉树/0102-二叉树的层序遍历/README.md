# 102. 二叉树的层序遍历

[力扣原题](https://leetcode.cn/problems/binary-tree-level-order-traversal/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

把二叉树每一层的节点值分别放进一个数组。

## 怎么想到这个方法

**队列按层遍历**

队列最初只放根。每轮开始记下当前队列大小 size，这些节点恰好组成当前层。弹出这 size 个节点，记录值并把孩子入队；新入队的孩子留给下一轮。通过固定本轮处理数量，把父层和子层分开。

## 跟着例子走一遍

根 1 的孩子为 2、3。第一轮 size=1，得到 [1] 并放入 2、3；第二轮 size=2，得到 [2,3]。

## 写代码时注意什么

不能在 for 条件里持续读取 q.size()，因为处理过程中队列大小会变化。空树直接返回空结果。

## 复杂度

- 时间：O(n)。
- 空间：O(w)，w 为最大层宽，不含输出。
