# 98. 验证二叉搜索树

[力扣原题](https://leetcode.cn/problems/validate-binary-search-tree/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

验证整棵树是否满足二叉搜索树条件。

## 怎么想到这个方法

**递归传递严格上下界**

每个节点不仅要和父节点比较，还必须服从所有祖先施加的范围。递归带上开区间 (low,high)，当前值必须严格位于其中；左子树继承 low，并把 high 改成当前值；右子树继承 high，并把 low 改成当前值。

## 跟着例子走一遍

树根 5，右孩子 7，而 7 的左孩子为 4。虽然 4 < 7，但它在 5 的右子树里，必须大于 5，范围检查会发现不合法。

## 写代码时注意什么

搜索树不允许相等值，用 <= 和 >= 排除边界。初始范围用 long long 的极值，保证 INT_MIN、INT_MAX 也能作为合法节点值。

## 复杂度

- 时间：O(n)。
- 空间：O(h)。
