# 76. 最小覆盖子串

[力扣原题](https://leetcode.cn/problems/minimum-window-substring/) · 困难 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

从 s 中找最短的连续子串，使它包含 t 中所有字符及其重复次数。

## 怎么想到这个方法

**计数滑动窗口**

need 记录每种字符还缺多少，missing 记录总共还缺几个字符。右端加入字符时，若该字符原本还缺，missing 减一，再把 need 减一；负数表示窗口里有多余的这种字符。missing 为 0 时已覆盖 t，尝试不断收缩左边界，并在收缩前记录更短答案。一旦移走了不可缺少的字符，停止收缩，继续扩张右边界。

## 跟着例子走一遍

s = ADOBECODEBANC，t = ABC。先得到覆盖窗口 ADOBEC；继续扩张和收缩，最终得到 BANC。窗口中多出来的 A、B、C 可以丢，但最后一个必需字符被移出时，就得重新扩张。

## 写代码时注意什么

t 中重复字符必须按次数覆盖。左端移出字符后，只有 need 从 0 变成正数才表示缺少；只判断字符是否出现过会漏掉重复次数。无解返回空字符串。

## 复杂度

- 时间：O(|s| + |t|)。
- 空间：O(Σ)，字符表为 256。
