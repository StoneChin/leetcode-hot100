# 239. 滑动窗口最大值

[力扣原题](https://leetcode.cn/problems/sliding-window-maximum/) · 困难 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

返回每个长度为 k 的滑动窗口里的最大值。

## 怎么想到这个方法

**单调双端队列**

队列存下标，所对应的值从队头到队尾递减。加入新数前，先从队头删除已经滑出窗口的下标，再从队尾删除小于或等于新数的候选：新数更大、过期更晚，这些旧数以后不可能成为最大值。加入当前下标后，队头就是当前窗口最大值。

## 跟着例子走一遍

nums = [1,3,-1,-3,5]，k = 3。3 入队时淘汰 1；前两个完整窗口最大值都是 3。5 到来时淘汰队尾的 -3、-1 和旧的 3，第三个窗口最大值变成 5。

## 写代码时注意什么

队列要存下标，才能判断是否过期。每个下标最多入队、出队各一次，因此队尾的 while 不会让总时间变成平方级。

## 复杂度

- 时间：O(n)。
- 空间：O(k)，不含输出。
