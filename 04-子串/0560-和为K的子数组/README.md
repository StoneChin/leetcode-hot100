# 560. 和为 K 的子数组

[力扣原题](https://leetcode.cn/problems/subarray-sum-equals-k/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

统计和恰好等于 k 的连续子数组个数。

## 怎么想到这个方法

**前缀和 + 出现次数**

设当前前缀和为 sum。若之前某个前缀和等于 sum - k，那么那一位置之后到当前的这一段和就是 k。哈希表保存每种前缀和出现了几次，每到一个位置，把 count[sum - k] 加入答案，再记录当前 sum。初始化 count[0] = 1，表示数组开始之前有一个空前缀。

## 跟着例子走一遍

nums = [1,1,1]，k = 2。前缀和依次为 1、2、3。到 2 时能找到前缀 0，得到前两个 1；到 3 时能找到前缀 1，得到后两个 1，所以答案是 2。

## 写代码时注意什么

有负数时，窗口的和不会随左右边界单调变化，不能套常规滑动窗口。先查询再记录，避免 k = 0 时把空子数组算进去；出现次数不能只存成布尔值。

## 复杂度

- 时间：平均 O(n)。
- 空间：O(n)。
