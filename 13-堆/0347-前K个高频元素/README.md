# 347. 前 K 个高频元素

[力扣原题](https://leetcode.cn/problems/top-k-frequent-elements/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

返回出现频率最高的 k 个不同元素。

## 怎么想到这个方法

**频率统计 + 频率桶**

先用哈希表统计每个值的次数。出现次数最多为 n，所以可以开 n+1 个桶，把出现 c 次的值放进 bucket[c]。然后从次数 n 向 1 倒序扫描，依次取元素直到收集 k 个。这样不用把所有值按频率排序，也满足题目要求的优于 O(n log n) 时间。

## 跟着例子走一遍

[1,1,1,2,2,3] 中，桶 3 放 1，桶 2 放 2，桶 1 放 3。k=2 时从高频桶拿到 1、2。

## 写代码时注意什么

桶下标是次数，桶里存的是原数值。题目保证最高频答案集合唯一，集合内部顺序不限；若同一桶有多个可选值，扫描到 k 个就停。

## 复杂度

- 时间：平均 O(n)。
- 空间：O(n)。
