# 15. 三数之和

[力扣原题](https://leetcode.cn/problems/3sum/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

找出和为 0 的所有三元组，结果中不能有重复组合。

## 怎么想到这个方法

**排序 + 固定一个数 + 双指针**

先排序，再固定第一个数 nums[i]，在它后面的区间用左右指针找两数和。总和小于 0 时左指针右移，让和增大；大于 0 时右指针左移，让和减小。等于 0 时记录答案，并跳过两端相同的值。固定的第一个数也要跳重，这样同一组数不会以不同下标重复出现。

## 跟着例子走一遍

[-1,0,1,2,-1,-4] 排序为 [-4,-1,-1,0,1,2]。固定第一个 -1，可以找到 [-1,-1,2] 和 [-1,0,1]；下一轮的 -1 与前一个相同，直接跳过。

## 写代码时注意什么

返回的是数值组合，不是下标。跳过重复值要发生在记录答案之后，否则可能错过 [-1,-1,2] 这类含重复数的合法组合。此解法会改变输入顺序。

## 复杂度

- 时间：O(n²)。
- 空间：O(log n) 排序栈空间，不含输出。
