# 11. 盛最多水的容器

[力扣原题](https://leetcode.cn/problems/container-with-most-water/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

从两根竖线中选择一对，使它们与横轴组成的容器容量最大。

## 怎么想到这个方法

**两端向内移动短板**

容量等于两端距离乘以较矮的高度。先取最远的两端，再移动较矮的一端：如果保留短板、只移动高板，宽度减小，高度还不会超过短板，容量不可能变大。因此短板这一端已经没有继续保留的价值，可以安全丢弃。每次计算当前容量并更新答案。

## 跟着例子走一遍

高度 [1,8,6,2,5,4,8,3,7]，最外侧容量为 8。左边 1 较矮，左指针右移到 8，此时右端为 7，容量是 7 × 7 = 49。

## 写代码时注意什么

比较的是两端高度，不是下标。两端一样高时移动任意一边即可，因为保留任意一根都无法在更小宽度下超过当前容量。

## 复杂度

- 时间：O(n)。
- 空间：O(1)。
