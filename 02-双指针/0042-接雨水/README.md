# 42. 接雨水

[力扣原题](https://leetcode.cn/problems/trapping-rain-water/) · 困难 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

给定每根柱子的高度，求下雨后能存下多少水。

## 怎么想到这个方法

**双指针维护两侧最高墙**

一个位置的水深由左右最高墙中较低的一面决定，再减去当前位置的高度。左右指针向中间收缩，同时更新 leftMax 和 rightMax。如果 leftMax 较小，左侧当前位置的水量就能确定：右侧至少已有 rightMax 这么高，不会成为更低的限制。先结算左侧并右移；反之结算右侧。

## 跟着例子走一遍

[3,0,2,0,4] 的左侧最高墙为 3，右边有高度 4 的墙。中间三个位置分别存 3、1、3 单位水，总量为 7。算法按位置结算，不需要模拟水流。

## 写代码时注意什么

不要直接用左右当前柱子之差算水量，要用已经见过的最高墙。先更新最高墙再计算，可保证本次贡献非负；空数组也会自然返回 0。

## 复杂度

- 时间：O(n)。
- 空间：O(1)。
