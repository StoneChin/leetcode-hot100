# 283. 移动零

[力扣原题](https://leetcode.cn/problems/move-zeroes/) · 简单 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

原地把所有 0 移到末尾，并保持非零元素的相对顺序。

## 怎么想到这个方法

**读写双指针**

write 指向下一个非零元素该写入的位置。read 从左到右扫描，遇到非零数就写到 write，再让 write 前进。扫描结束后，前 write 个位置已经按原顺序放好了所有非零数，把剩余位置补成 0 即可。write 永远不会超过 read，所以覆盖写入不会破坏尚未读取的数据。

## 跟着例子走一遍

[0,1,0,3,12] 依次写入 1、3、12，write 最后为 3。再把下标 3、4 写成 0，得到 [1,3,12,0,0]。

## 写代码时注意什么

不能从两端随意交换零和非零数，那样会打乱非零数的相对顺序。全零数组和没有零的数组都可直接走同一套流程。

## 复杂度

- 时间：O(n)。
- 空间：O(1)。
