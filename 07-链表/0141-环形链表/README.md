# 141. 环形链表

[力扣原题](https://leetcode.cn/problems/linked-list-cycle/) · 简单 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

判断单链表是否存在环。

## 怎么想到这个方法

**快慢指针**

慢指针每次走一步，快指针每次走两步。无环时，快指针最终走到空节点；有环时，两者都会进入环，快指针每轮相对慢指针多走一步，最终一定追上。相遇时比较节点地址。

## 跟着例子走一遍

链表 1→2→3→2 中，慢指针进入 2、3，快指针在环内绕行，最后会在某个环内节点与慢指针重合。相遇点不一定是环入口。

## 写代码时注意什么

循环条件要同时判断 fast 和 fast->next。先移动再比较，若一开始就比较，两者都在 head 会把所有非空链表误判为有环。

## 复杂度

- 时间：O(n)。
- 空间：O(1)。
