# 148. 排序链表

[力扣原题](https://leetcode.cn/problems/sort-list/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

将单链表按节点值升序排序，要求 O(n log n) 时间。

## 怎么想到这个方法

**链表归并排序**

用快慢指针找到中间位置，从中间断开为两条链表，分别递归排序，再把两条有序链表合并。链表不能像数组一样随机访问，归并只需要比较头节点、修改连接，非常适合这里。每层合并总共处理 n 个节点，切半产生 log n 层。

## 跟着例子走一遍

4→2→1→3 分成 4→2 和 1→3，再各自拆成单节点。底层合并成 2→4、1→3，最后得到 1→2→3→4。

## 写代码时注意什么

切分后一定把前半段尾部 next 设为空，否则递归可能仍收到原链表。此实现使用递归，辅助空间为 O(log n)；若要严格常数空间，可改成自底向上归并。

## 复杂度

- 时间：O(n log n)。
- 空间：O(log n) 递归栈。
