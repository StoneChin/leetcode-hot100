# 23. 合并 K 个升序链表

[力扣原题](https://leetcode.cn/problems/merge-k-sorted-lists/) · 困难 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

将 k 条升序链表合并成一条升序链表。

## 怎么想到这个方法

**最小堆维护各条链表的头**

每条链表当前最小的数一定在它的头部，把所有非空链表的头放进最小堆。每次取出堆顶，也就是所有剩余节点中的最小值，接到结果末尾，然后将它的后继放入堆。堆内最多有 k 个候选，不必每轮扫描所有链表。

## 跟着例子走一遍

[1→4,1→3,2→6] 初始堆里是 1、1、2。取出某个 1 后，放入它同链表的下一个节点；重复后得到 1→1→2→3→4→6。

## 写代码时注意什么

priority_queue 默认是最大堆，自定义比较要让较小 val 优先。空链表不要入堆。这里重连已有节点，不创建结果节点。

## 复杂度

- 时间：O(N log(k+1))，N 为总节点数。
- 空间：O(k)。
