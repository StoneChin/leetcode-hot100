# 138. 随机链表的复制

[力扣原题](https://leetcode.cn/problems/copy-list-with-random-pointer/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

深拷贝带 next 和 random 指针的链表，所有新指针都要指向新节点。

## 怎么想到这个方法

**两趟遍历 + 节点映射**

第一趟只创建节点，并建立“旧地址 → 新地址”的映射。第二趟再补 next 和 random：旧节点指向哪个旧地址，新节点就指向那个地址对应的新节点。先把所有节点建好，random 无论指向前面、后面还是自己，都能在表中找到。

## 跟着例子走一遍

A 的 random 指向 B，B 的 random 指向自己。创建 A′、B′ 后，将 A′.random 设为 B′，B′.random 也设为 B′；不能让新节点继续指向旧的 B。

## 写代码时注意什么

不能以 val 作为映射键，因为节点值可以重复。空指针单独映射为空；本方案用 O(n) 空间换取清晰的构造过程，不修改原链表。

## 复杂度

- 时间：平均 O(n)。
- 空间：O(n)，不含新链表。
