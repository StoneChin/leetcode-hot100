# 206. 反转链表

[力扣原题](https://leetcode.cn/problems/reverse-linked-list/) · 简单 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

反转单链表，返回新的头节点。

## 怎么想到这个方法

**逐个反转 next**

prev 表示已经反转好的部分，cur 表示还没处理的部分。先保存 cur->next，避免断开后丢失剩余链表；再让 cur->next 指向 prev；最后将 prev 移到 cur，cur 移到保存的后继。直到 cur 为空，prev 就是新头。

## 跟着例子走一遍

1→2→3：处理 1 后得到 1→空，剩余 2→3；处理 2 后得到 2→1→空；处理 3 后得到 3→2→1→空。

## 写代码时注意什么

必须先保存后继再改 next。最终返回 prev，而不是已经为空的 cur。该操作会改变原链表的连接。

## 复杂度

- 时间：O(n)。
- 空间：O(1)。
