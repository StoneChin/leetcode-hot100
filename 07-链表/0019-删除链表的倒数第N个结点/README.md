# 19. 删除链表的倒数第 N 个结点

[力扣原题](https://leetcode.cn/problems/remove-nth-node-from-end-of-list/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

删除链表倒数第 n 个节点，返回头节点。

## 怎么想到这个方法

**固定间距的快慢指针**

在头前加哑节点，让 fast 和 slow 都从它出发。fast 先走 n 步，再让两者同步前进，直到 fast 位于最后一个节点。此时 slow 恰好停在待删节点的前一个位置，修改 slow->next 即可跳过目标。哑节点让删除头节点也成为普通的连接修改。

## 跟着例子走一遍

1→2→3→4→5，n = 2。快指针先领先 2 步，随后一起走；快指针到 5 时，慢指针在 3，跳过它后面的 4。

## 写代码时注意什么

题目保证 n 合法。我们只断开节点，不在解法里 delete 它，避免对外部持有的节点地址作额外所有权假设；本地测试由调用方统一管理节点。

## 复杂度

- 时间：O(L)，L 为链表长度。
- 空间：O(1)。
