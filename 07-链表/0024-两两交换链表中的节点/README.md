# 24. 两两交换链表中的节点

[力扣原题](https://leetcode.cn/problems/swap-nodes-in-pairs/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

两两交换相邻节点，不能只交换节点的值。

## 怎么想到这个方法

**成对调整三条连接**

prev 指向当前这对节点前面的节点，a、b 是本轮要交换的两个节点。先让 a 接上 b 后面的剩余链表，再让 b 指向 a，最后让 prev 接上 b。交换后 a 是这一对的尾部，所以 prev 移到 a，继续处理下一对。

## 跟着例子走一遍

1→2→3→4：第一轮变为 2→1→3→4，prev 停在 1；第二轮交换 3、4，得到 2→1→4→3。

## 写代码时注意什么

循环必须保证还剩两个节点。先保存 a、b，再改连接；不要把 prev 前进到 b，它是交换后的头，下一轮的前驱应是 a。

## 复杂度

- 时间：O(n)。
- 空间：O(1)。
