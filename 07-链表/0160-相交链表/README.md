# 160. 相交链表

[力扣原题](https://leetcode.cn/problems/intersection-of-two-linked-lists/) · 简单 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

找出两条无环链表真正共享的第一个节点。

## 怎么想到这个方法

**双指针交换起点**

两个指针分别从 A、B 出发，走到空指针后转到另一条链表的头。这样两者都会走过 A 与 B 的总长度，长度差被抵消。若有公共尾部，它们会在公共入口相遇；若不相交，最终同时变成空指针。判断用的是节点地址，节点值相等不代表相交。

## 跟着例子走一遍

A 的独有部分长 2，B 的独有部分长 3，公共部分长 2。A 指针先走 A 再走 B，B 指针先走 B 再走 A，最终都走过 2+3 个独有节点后进入公共部分。

## 写代码时注意什么

这里依赖链表无环。不要修改 next 来强行拼接两条链表，也不要比较 val；两个值为 8 的不同节点仍然不算相交。

## 复杂度

- 时间：O(m+n)。
- 空间：O(1)。
