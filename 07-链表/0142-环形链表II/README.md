# 142. 环形链表 II

[力扣原题](https://leetcode.cn/problems/linked-list-cycle-ii/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

若链表有环，返回环的入口节点；否则返回空。

## 怎么想到这个方法

**相遇后同步走向环入口**

先用快慢指针找到环内相遇点。设头到入口距离为 a，入口到相遇点沿前进方向距离为 b，环长为 c。相遇时快指针比慢指针多走若干圈，可得 a+b 是 c 的整数倍。因此让一个指针回到头，另一个留在相遇点，都每次走一步；走 a 步后，一个刚到入口，另一个也绕到入口。

## 跟着例子走一遍

头到入口有 2 步、环长为 3 时，相遇点到入口的剩余距离与 2 对环长取模相同。两个指针同步前进，第一次相遇的位置就是入口。

## 写代码时注意什么

第一次快慢相遇只能证明有环，不能直接当成入口。无环时要返回空；第二阶段两个指针的速度都必须是一。

## 复杂度

- 时间：O(n)。
- 空间：O(1)。
