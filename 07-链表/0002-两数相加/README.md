# 2. 两数相加

[力扣原题](https://leetcode.cn/problems/add-two-numbers/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

两条链表按低位在前存储整数，返回它们相加后的链表。

## 怎么想到这个方法

**逐位相加并保留进位**

既然个位在头部，就能像竖式加法一样从头向后算。每轮把两个当前位和 carry 相加，新节点的值为 sum % 10，新进位为 sum / 10。较短链表耗尽后按 0 处理；两条链表都结束但还有进位时，还要再生成一位。

## 跟着例子走一遍

2→4→3 表示 342，5→6→4 表示 465。逐位相加得到 7、0（进位 1）、8，结果 7→0→8 表示 807。

## 写代码时注意什么

循环条件必须包含 carry，否则 9 + 1 会丢掉最高位 1。结果新建节点，原链表不会被改动；本地使用者需要释放返回的节点。

## 复杂度

- 时间：O(max(m,n))。
- 空间：O(1) 辅助空间，输出 O(max(m,n))。
