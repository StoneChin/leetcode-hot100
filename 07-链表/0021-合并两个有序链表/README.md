# 21. 合并两个有序链表

[力扣原题](https://leetcode.cn/problems/merge-two-sorted-lists/) · 简单 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

将两条升序链表合并成一条升序链表。

## 怎么想到这个方法

**哑节点 + 双指针合并**

用一个哑节点作为结果的临时起点，tail 指向结果尾部。每次比较两条链表当前节点的值，把较小的节点接到 tail 后面，并前进对应链表的指针。某条链表耗尽后，另一条剩余部分已经有序，可以整体接上。

## 跟着例子走一遍

1→3 和 2→4：先接 1，再接 2，再接 3，最后把剩余的 4 接上，结果为 1→2→3→4。

## 写代码时注意什么

这里复用原节点，会改变原链表连接。哑节点本身不能返回，要返回 dummy.next。相等时取任意一边都正确，本实现优先取左边。

## 复杂度

- 时间：O(m+n)。
- 空间：O(1)。
