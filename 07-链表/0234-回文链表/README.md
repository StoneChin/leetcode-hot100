# 234. 回文链表

[力扣原题](https://leetcode.cn/problems/palindrome-linked-list/) · 简单 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

判断链表的节点值从前向后与从后向前是否相同。

## 怎么想到这个方法

**找中点 + 反转后半段**

快指针走两步，慢指针走一步，让慢指针停在前半段末尾。反转它后面的链表，再从头节点与反转后的头同时比较；后半段比较完就够了，奇数长度的中心节点不影响回文。比较结束后再反转一次，把链表恢复。

## 跟着例子走一遍

1→2→2→1 的前半段末尾是第一个 2，后半段反转成 1→2。与前面的 1→2 逐个比较，全部相等。对于 1→2→1，中间的 2 不参与比较。

## 写代码时注意什么

发现不等时不要直接返回，否则来不及恢复链表。用布尔值保存结果，再统一恢复连接。空链表和单节点直接为真。

## 复杂度

- 时间：O(n)。
- 空间：O(1)。
