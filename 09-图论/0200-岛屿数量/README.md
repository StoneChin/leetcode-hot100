# 200. 岛屿数量

[力扣原题](https://leetcode.cn/problems/number-of-islands/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

统计由上下左右相连的陆地组成的岛屿数量。

## 怎么想到这个方法

**深度优先搜索淹没陆地**

逐格扫描，遇到尚未访问的陆地，就发现一个新岛，答案加一。随后从这一格出发搜索相邻陆地，把整个岛改成水，作为已访问标记。以后再扫描到这个岛的其他格子时，它们已经是水，不会重复计数。

## 跟着例子走一遍

网格 [[1,1,0],[0,1,0],[1,0,1]] 中，上方三格连成一岛，左下、右下各是一岛，答案为 3。对角接触不算连通。

## 写代码时注意什么

进入搜索后先标记再向邻居递归，否则相邻两格会互相反复访问。这里会修改输入；若需要保留网格，应另开 visited。大岛可能使递归栈达到 O(mn)。

## 复杂度

- 时间：O(mn)。
- 空间：O(mn) 最坏递归栈。
