# 994. 腐烂的橘子

[力扣原题](https://leetcode.cn/problems/rotting-oranges/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

每分钟腐烂橘子感染相邻新鲜橘子，求全部腐烂所需的最少分钟。

## 怎么想到这个方法

**多源广度优先搜索**

把一开始所有腐烂橘子都放入队列，它们是同时扩散的多个源。队列每一层表示同一分钟内能够感染的橘子，按层向外扩张。统计新鲜橘子数量，每感染一个就减一。新鲜数量归零时返回层数；队列耗尽仍有新鲜橘子，说明存在无法到达的区域。

## 跟着例子走一遍

[[2,1,1],[1,1,0],[0,1,1]] 从左上角扩散，最远的新鲜橘子在第 4 分钟腐烂，因此返回 4。若一开始没有新鲜橘子，返回 0。

## 写代码时注意什么

入队时就标记腐烂，防止被多个邻居重复入队。分钟按整层计，不能每处理一个橘子就加一。没有腐烂源但有新鲜橘子时应返回 -1。

## 复杂度

- 时间：O(mn)。
- 空间：O(mn)。
