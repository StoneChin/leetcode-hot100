# 207. 课程表

[力扣原题](https://leetcode.cn/problems/course-schedule/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

给定课程先修关系，判断能否完成全部课程。

## 怎么想到这个方法

**入度拓扑排序**

把先修课 b 到后修课 a 画一条有向边，a 的入度表示还有多少门先修课没完成。先将所有入度为 0 的课入队，逐个完成并减少后续课程的入度；降为 0 就入队。如果最终完成数等于总课程数，存在合法顺序；否则剩余部分有环，互相等待无法开始。

## 跟着例子走一遍

2 门课、关系 [[1,0]]，先完成 0，再将 1 的入度减为 0，两门都完成。加入 [0,1] 后，两门入度都为 1，初始队列为空，因此无法完成。

## 写代码时注意什么

边方向应是先修课指向后修课。没有任何关系的孤立课程也要放进初始队列。只检查某个连通块不够，课程图可能包含多块。

## 复杂度

- 空间：O(V+E)。
