# 208. 实现 Trie (前缀树)

[力扣原题](https://leetcode.cn/problems/implement-trie-prefix-tree/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

支持插入单词、查询完整单词、查询是否存在给定前缀。

## 怎么想到这个方法

**按字符建前缀树**

根代表空前缀，每条边代表一个字符。插入时沿字符向下走，没有子节点就创建，最后标记 end。查询前缀只需确认整条路径存在；查询单词还要求末尾节点有 end 标记。用 vector 保存节点、整数下标保存连接，内存由容器统一管理。

## 跟着例子走一遍

插入 apple 后，startsWith(app) 为真，但 search(app) 为假，因为 p 所在节点不是单词结尾；再插入 app 后，search(app) 才变为真。

## 写代码时注意什么

路径存在不等于完整单词存在。vector 扩容会使引用失效，所以创建节点时不要跨 emplace_back 持有节点引用。本实现面向小写英文字母。

## 复杂度

- 时间：每次操作 O(L)，L 为本次字符串长度。
- 空间：O(ΣL)，按所有插入字符总量计，字母表大小固定。
