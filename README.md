# LeetCode 热题 100 · C++17

按[力扣官方热题 100 题单](https://leetcode.cn/studyplan/top-100-liked/)的 **17 个分类、100 道题**整理，分类、题名与顺序核对于 2026-10-12。题意只作简述，完整约束和原题以题目链接为准。

每题目录包含 `solution.cpp` 和 `README.md`。代码提供一套完整解法，注释说明关键操作；解析按问题、思路、例子、边界和复杂度展开。部分题目采用更方便理解和验证的方案，例如第 148 题递归归并排序、第 215 题最小堆，文档注明对应复杂度。

## 怎么用

按下面目录进入题目，先看解析，再对照代码。提交到力扣时复制 `solution.cpp` 全部内容，选择 C++17；不要定义 `LOCAL_TEST`。链表和二叉树的节点类型由力扣提供，设计题按原题接口提交。

本地需要 Python 3.9+ 和支持 C++17 的编译器（默认 `g++`）：

```bash
# 校验目录完整性、编译各题并执行回归用例
python3 scripts/check.py

# 只检查指定题目
python3 scripts/check.py --ids 1 25 146

# 更换编译器或控制并发数
python3 scripts/check.py --compiler clang++ --jobs 4
```

用例包括每题的基本行为，以及重点题的边界、结构恢复和指针身份检查。它们用于本地回归，不能代替力扣的完整评测；项目不宣称已在线提交通过。额外的穷举对照检查见 [tests/README.md](tests/README.md)。编译产物写入临时目录，退出后自动清理。

## 约定

复杂度中的 n 通常表示元素数，m、n 在矩阵题中表示行列数，h 表示树高；各题有额外参数时会单独说明。哈希表操作使用平均复杂度，递归空间计入调用栈，输出空间是否计入在每题注明。

会修改输入的算法在解析中说明。新建链表或树的解法将结果交给调用者管理，测试会释放动态创建的结果。所有题目相互独立，不能把多个 `Solution` 类直接拼在一个翻译单元里。

题目元数据保存在 [problems.json](problems.json)，校验脚本据此检查题目数量、分类、文件和本地用例。
