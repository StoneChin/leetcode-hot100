# 33. 搜索旋转排序数组

[力扣原题](https://leetcode.cn/problems/search-in-rotated-sorted-array/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

在无重复元素的旋转升序数组中寻找 target，下标不存在则返回 -1。

## 怎么想到这个方法

**识别有序半边再二分**

每次取 mid 后，左右两半至少一半有序。如果 nums[l]<=nums[mid]，左半有序，判断目标是否落在 [nums[l],nums[mid])；在就保留左边，否则去右边。若左半无序，右半一定有序，用 (nums[mid],nums[r]] 作同样判断。

## 跟着例子走一遍

[4,5,6,7,0,1,2] 查 0，中点是 7，左半有序但 0 不在其范围，转去右边；右侧 [0,1,2] 再普通缩小区间即可找到下标 4。

## 写代码时注意什么

比较必须带正确端点，尤其 nums[l]<=nums[mid] 的等号可处理只剩一个或两个元素的情况。本方法依赖元素不重复，重复值可能使有序侧无法判断。

## 复杂度

- 时间：O(log n)。
- 空间：O(1)。
