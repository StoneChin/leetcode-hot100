# 35. 搜索插入位置

[力扣原题](https://leetcode.cn/problems/search-insert-position/) · 简单 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

在有序数组中返回 target 的下标，若不存在返回保持有序的插入位置。

## 怎么想到这个方法

**寻找第一个不小于 target 的位置**

用左闭右开区间 [l,r) 搜索第一个 >=target 的位置。mid 比目标小时，它以及左边都不可能是答案，令 l=mid+1；否则 mid 仍可能是第一个合法位置，令 r=mid。l==r 时，这个边界就是答案，也可以等于数组长度。

## 跟着例子走一遍

[1,3,5,6] 查 2，最终边界停在下标 1，即插在 3 前面；查 7 则停在 4，即末尾。

## 写代码时注意什么

不要在等于 target 时立即退出，保留统一的边界语义更容易复用。右边界初始为 n，不会访问 nums[n]，因为 mid 始终位于未空区间内部。

## 复杂度

- 时间：O(log n)。
- 空间：O(1)。
