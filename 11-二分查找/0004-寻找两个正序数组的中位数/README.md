# 4. 寻找两个正序数组的中位数

[力扣原题](https://leetcode.cn/problems/median-of-two-sorted-arrays/) · 困难 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

在两个升序数组中求合并后的中位数，要求对数时间。

## 怎么想到这个方法

**在较短数组上二分分割线**

把两个数组各切成左右两部分，使左半总数为 (m+n+1)/2。设第一个数组左边取 i 个，第二个就取 j=half-i 个。在较短数组上二分 i。若两边左侧最大值都不超过对侧右侧最小值，分割正确；否则 A 左边过大就减小 i，B 左边过大就增大 i。奇数总长取左半最大，偶数取左半最大与右半最小的平均。

## 跟着例子走一遍

A=[1,3]，B=[2]，先交换以便在 [2] 上二分。正确划分左半为 [1,2]、右半为 [3]，总长为奇数，中位数为左半最大值 2。

## 写代码时注意什么

空的一侧用负无穷或正无穷哨兵处理，不访问越界元素。偶数时先转为 double 再求和，避免两个 int 相加溢出。题目保证总长度非零。

## 复杂度

- 时间：O(log(min(m,n)+1))。
- 空间：O(1)。
