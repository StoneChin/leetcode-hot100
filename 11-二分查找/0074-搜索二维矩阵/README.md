# 74. 搜索二维矩阵

[力扣原题](https://leetcode.cn/problems/search-a-2d-matrix/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

在各行递增且下一行首元素大于上一行末元素的矩阵中查找目标。

## 怎么想到这个方法

**把矩阵视作一维有序数组**

这里整个矩阵按行展开后有序，可以直接二分长度 m*n 的虚拟数组。一维下标 mid 对应行 mid/n、列 mid%n，不必真的复制矩阵。与普通二分相同，依据中间值与 target 的比较缩小区间。

## 跟着例子走一遍

[[1,3,5],[7,9,11]] 展开为 [1,3,5,7,9,11]。虚拟下标 4 对应 (1,1)，值为 9。查 9 就与在一维数组里查找一样。

## 写代码时注意什么

本题比第 240 题多了跨行有序条件，只有满足这一条件才能展开二分。先检查空矩阵，避免访问 matrix[0] 或除以 0。

## 复杂度

- 时间：O(log(mn))。
- 空间：O(1)。
