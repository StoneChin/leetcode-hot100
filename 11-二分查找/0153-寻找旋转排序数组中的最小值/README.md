# 153. 寻找旋转排序数组中的最小值

[力扣原题](https://leetcode.cn/problems/find-minimum-in-rotated-sorted-array/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

返回无重复旋转有序数组中的最小值。

## 怎么想到这个方法

**与右端点比较寻找旋转分界**

mid 与右端比较即可判断最小值在哪边。若 nums[mid]>nums[r]，mid 位于较大的前段，最小值一定在它右边，令 l=mid+1；否则 mid 到右端有序，最小值在左侧或就是 mid，令 r=mid。区间最终缩成一个位置。

## 跟着例子走一遍

[3,4,5,1,2] 中，mid 为 5，大于右端 2，舍弃左边；剩下 [1,2]，mid 为 1，小于 2，保留 1，答案为 1。

## 写代码时注意什么

第二种情况不能写 r=mid-1，因为 mid 本身可能是最小值。数组本来没有旋转时，这个流程也会一路收缩到第一个元素。

## 复杂度

- 时间：O(log n)。
- 空间：O(1)。
