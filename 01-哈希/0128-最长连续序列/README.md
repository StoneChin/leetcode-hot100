# 128. 最长连续序列

[力扣原题](https://leetcode.cn/problems/longest-consecutive-sequence/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

求数组中最长的连续整数序列长度，不要求它们在原数组中相邻。

## 怎么想到这个方法

**哈希集合寻找连续段起点**

先把所有数放进集合去重。对于 x，如果 x - 1 也存在，说明 x 不是连续段的起点，直接跳过；只有前一个数不存在时，才从 x 开始不断找 x + 1。虽然代码有两层循环，但每个连续段只展开一次，每个数最多被展开访问一次。

## 跟着例子走一遍

[100,4,200,1,3,2] 中只有 100、200、1 是各段的起点。从 1 出发依次找到 2、3、4，长度为 4；2、3、4 都不会再启动向后搜索。

## 写代码时注意什么

遍历去重后的集合。如果遍历原数组，大量重复起点会让同一段被反复扫描。代码额外判断整数边界，避免 x - 1 或 y + 1 溢出。

## 复杂度

- 时间：平均 O(n)。
- 空间：O(n)。
