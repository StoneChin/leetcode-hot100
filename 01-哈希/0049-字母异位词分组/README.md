# 49. 字母异位词分组

[力扣原题](https://leetcode.cn/problems/group-anagrams/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

把字母种类和数量相同的字符串放在同一组。

## 怎么想到这个方法

**排序后的字符串作键**

两个字符串是字母异位词，意味着排序后完全一样。例如 eat 和 tea 都变成 aet。遍历每个字符串，复制一份用于排序，把原字符串加入这个键对应的分组。键负责判断归属，值保留原来的拼写；最后取出所有分组。

## 跟着例子走一遍

[eat,tea,tan,ate,nat,bat] 的键依次是 aet、aet、ant、aet、ant、abt，所以得到三组。空字符串排序后仍为空，也能正常作为键。

## 写代码时注意什么

不要直接排序输入字符串，否则输出会丢失原来的拼写。题目不要求组与组之间的顺序，unordered_map 的遍历顺序不影响正确性。

## 复杂度

- 时间：O(nk log k)，n 为字符串个数，k 为最大长度。
- 空间：O(nk)，包含分组结果。
