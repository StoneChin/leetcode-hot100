# 1. 两数之和

[力扣原题](https://leetcode.cn/problems/two-sum/) · 简单 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

在数组里找两个不同位置，使它们的和等于 target，返回下标。

## 怎么想到这个方法

**一次遍历 + 哈希表**

读到 x 时，需要的另一个数就是 target - x。用哈希表保存已经读过的数及其下标：先查补数，找到了就返回；没找到才把 x 放进去。这样表里的下标一定在当前位置之前，同一个元素不会被用两次。比起枚举所有数对，我们把“回头找一个数”变成了一次查询。

## 跟着例子走一遍

nums = [2,7,11,15]，target = 9。先记录 2 的下标 0；读到 7 时，表里已经有 9 - 7 = 2，于是返回 [0,1]。对于 [3,3]，第二个 3 同样能找到第一个 3。

## 写代码时注意什么

一定先查再存。若先存，target = 6、当前数为 3 时，可能错误地匹配到自己。

## 复杂度

- 时间：平均 O(n)。
- 空间：O(n)。
