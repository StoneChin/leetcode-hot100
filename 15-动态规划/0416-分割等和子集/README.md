# 416. 分割等和子集

[力扣原题](https://leetcode.cn/problems/partition-equal-subset-sum/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

判断能否将正整数数组分成元素和相等的两个子集。

## 怎么想到这个方法

**一维 0/1 背包可达性**

总和为奇数一定不行。总和为偶数时，只需选出和为 total/2 的一个子集，剩余自然等和。dp[s] 表示当前处理过的数能否凑出 s，初始只有 dp[0] 为真。每读到 x，从 target 向 x 倒序更新 dp[s] |= dp[s-x]，让每个数最多使用一次。

## 跟着例子走一遍

[1,5,11,5] 总和为 22，目标为 11。单独选 11 就能达成，另一组 1+5+5 也为 11。

## 写代码时注意什么

必须倒序扫描金额，正序会让本轮刚更新的状态被再次使用，把同一个元素选多次。此题是每个数一次的 0/1 背包，与零钱兑换不同。

## 复杂度

- 时间：O(n·target)。
- 空间：O(target)。
