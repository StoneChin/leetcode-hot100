# 152. 乘积最大子数组

[力扣原题](https://leetcode.cn/problems/maximum-product-subarray/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

求非空连续子数组的最大乘积。

## 怎么想到这个方法

**同时维护最大与最小结尾乘积**

负数会把大小关系翻转，因此不能只保留最大乘积。hi、lo 分别表示以当前位置结尾的最大、最小乘积。遇到 x，候选有 x 自己、旧 hi*x、旧 lo*x，同时求新最大与新最小。零会把旧乘积清为 0，下一位置也能从自身重新开始。

## 跟着例子走一遍

[-2,3,-4] 中，读到 3 时最大结尾为 3、最小为 -6；读到 -4 时，最小值 -6 乘 -4 反而成为最大值 24。

## 写代码时注意什么

两个状态必须使用同一轮的旧值，先计算 nextHi、nextLo，再更新。初始化为首元素，保证全负或单元素数组仍选非空子数组。

## 复杂度

- 时间：O(n)。
- 空间：O(1)。
