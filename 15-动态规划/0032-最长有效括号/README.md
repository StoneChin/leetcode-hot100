# 32. 最长有效括号

[力扣原题](https://leetcode.cn/problems/longest-valid-parentheses/) · 困难 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

求最长连续合法括号子串的长度。

## 怎么想到这个方法

**栈保存匹配边界**

栈先放 -1 作为左侧边界。遇到 (，压入下标；遇到 )，先弹出一次，表示匹配一个左括号。若栈空，说明这个 ) 无法匹配，将它的下标压入，作为新边界；否则当前位置减栈顶，就是以当前位置结尾的最长合法长度。栈顶可能是未匹配左括号，也可能是最后一个非法右括号。

## 跟着例子走一遍

s = )()())。第一个 ) 设新边界 0；到下标 2 得到长度 2，到下标 4 得到长度 4，对应 ()()；最后一个 ) 不能匹配，重设边界。

## 写代码时注意什么

不能只统计成功匹配了多少对，因为不同合法段之间可能隔着非法字符。-1 是为了让从下标 0 开始的合法串直接用 i-(-1) 算长度。

## 复杂度

- 时间：O(n)。
- 空间：O(n)。
