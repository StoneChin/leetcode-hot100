# 322. 零钱兑换

[力扣原题](https://leetcode.cn/problems/coin-change/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

用给定面额的无限硬币凑出 amount，返回最少数量，凑不出返回 -1。

## 怎么想到这个方法

**按金额计算最少硬币数**

dp[x] 表示恰好凑出金额 x 的最少硬币数。dp[0]=0，其余先设为不可达。枚举金额 x 与最后使用的硬币 c，如果 c<=x，就尝试 dp[x-c]+1。所有硬币都试过后，取最小值；最后检查 dp[amount] 是否仍为不可达。

## 跟着例子走一遍

coins=[1,2,5]，amount=11。最后选 5 时可以从 dp[6]=2 转移得到 3，对应 5+5+1。coins=[2]、amount=3 时无法凑出，返回 -1。

## 写代码时注意什么

按最大面额优先并不总最优，例如 [1,3,4] 凑 6，贪心要 3 枚，而 3+3 只要 2 枚。用 amount+1 作无穷，避免 INT_MAX+1 溢出。

## 复杂度

- 时间：O(amount·k)，k 为面额数。
- 空间：O(amount)。
