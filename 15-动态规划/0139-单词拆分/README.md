# 139. 单词拆分

[力扣原题](https://leetcode.cn/problems/word-break/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

判断字符串能否拆成字典里的若干单词，单词可重复用。

## 怎么想到这个方法

**前缀能否被完整拆分**

dp[i] 表示前 i 个字符能够完整拆分。dp[0]=true，表示空前缀已完成。对每个结束位置 i，枚举最后一个单词的起点 j；只有 dp[j] 为真，且 s[j..i) 在字典里时，dp[i] 才能为真。用集合查词，并用字典最大单词长度限制枚举范围。

## 跟着例子走一遍

s=leetcode，字典有 leet、code。dp[4] 因 leet 为真，dp[8] 从 dp[4] 接上 code 也为真。字典单词可以在不同位置反复匹配。

## 写代码时注意什么

不能只要某处找到字典单词就贪心切开，例如 cars 配 [car,ca,rs]，先切 car 会失败，而 ca+rs 可行。C++ substr 和字符串哈希都有长度成本，复杂度需要计算进去。

## 复杂度

- 时间：平均 O(nL²)，L 为最大字典单词长度；建表另需字典总字符量。
- 空间：O(n+D+L)，D 为字典存储字符量。
