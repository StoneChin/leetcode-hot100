# 70. 爬楼梯

[力扣原题](https://leetcode.cn/problems/climbing-stairs/) · 简单 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

每次爬 1 或 2 级，求到达第 n 级的不同走法数。

## 怎么想到这个方法

**只保留前两个状态**

到第 i 级的最后一步只有两种来源：从 i-1 爬一级，或者从 i-2 爬两级，两类走法不重叠，所以 f(i)=f(i-1)+f(i-2)。设 f(0)=1 表示不走的一种方式，f(1)=1。滚动保存前两项，不需要整个数组。

## 跟着例子走一遍

n=4 时，状态依次为 f(0)=1、f(1)=1、f(2)=2、f(3)=3、f(4)=5，所以有 5 种走法。

## 写代码时注意什么

f(0)=1 是用于拼接路径的计数初值，不应设为 0。题目 n<=45，int 能容纳答案；更大的 n 需要大整数或取模。

## 复杂度

- 时间：O(n)。
- 空间：O(1)。
