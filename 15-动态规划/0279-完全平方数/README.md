# 279. 完全平方数

[力扣原题](https://leetcode.cn/problems/perfect-squares/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

求和为 n 的最少完全平方数个数，每个平方数可以重复使用。

## 怎么想到这个方法

**枚举最后一个平方数**

dp[x] 表示凑出 x 最少需要几个平方数，dp[0]=0。若最后选 j²，前面的部分就是 x-j²，因此候选为 dp[x-j²]+1。枚举所有不超过 x 的平方数取最小值。按 x 从小到大计算，依赖的状态都已经有答案。

## 跟着例子走一遍

n=12 时，可以由 4+4+4 得到 3 个；n=13 时，最后选 9，剩下 4 只需 1 个，总数为 2。

## 写代码时注意什么

平方数可以重复，所以无需限制某个 j² 用过几次。初始化为 n+1 足够表示尚无答案；平方数 1 总能凑出每个正整数。

## 复杂度

- 时间：O(n√n)。
- 空间：O(n)。
