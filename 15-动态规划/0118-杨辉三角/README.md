# 118. 杨辉三角

[力扣原题](https://leetcode.cn/problems/pascals-triangle/) · 简单 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

生成杨辉三角的前 numRows 行。

## 怎么想到这个方法

**按上一行构造下一行**

第 i 行有 i+1 个元素，两端固定为 1。中间第 j 项来自上一行的 j-1 与 j 两项相加。先把当前行全部初始化为 1，再只填中间位置，就不用单独处理两个边界。

## 跟着例子走一遍

前四行为 [1]、[1,1]、[1,2,1]、[1,3,3,1]，第四行中间的 3 分别由 1+2 和 2+1 得到。

## 写代码时注意什么

访问上一行只发生在中间元素循环中，第一行和第二行没有中间项，因此不会访问负下标。不需要额外补一行占位。

## 复杂度

- 时间：O(r²)，r=numRows。
- 空间：O(1) 额外空间，不含输出。
