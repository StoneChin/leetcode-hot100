# 198. 打家劫舍

[力扣原题](https://leetcode.cn/problems/house-robber/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

相邻两间房不能同时偷，求最多能拿到的金额。

## 怎么想到这个方法

**当前房屋偷或不偷**

处理当前金额 x 时，不偷则沿用前一间处理完后的最优值 one；偷则上一间必须不偷，收益为前两间最优值 two+x。取较大值作为当前答案，再滚动更新 two、one。初始都为 0，表示还没有处理房屋。

## 跟着例子走一遍

[2,7,9,3,1] 的最优值依次为 2、7、11、11、12，最后选择金额 2、9、1 的三间房。

## 写代码时注意什么

不能只比较相邻两间金额并贪心选大的，因为某次选择会影响后续是否能选。更新 two 前要保存 next，否则可能用到本轮已经改过的状态。

## 复杂度

- 时间：O(n)。
- 空间：O(1)。
