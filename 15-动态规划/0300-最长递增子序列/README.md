# 300. 最长递增子序列

[力扣原题](https://leetcode.cn/problems/longest-increasing-subsequence/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

求严格递增子序列的最大长度，子序列不要求连续。

## 怎么想到这个方法

**最小结尾数组 + 二分**

tails[len-1] 表示长度为 len 的递增子序列能够达到的最小结尾值。读到 x，用 lower_bound 找到第一个 >=x 的结尾，将它换成 x；若找不到，就追加 x，说明最长长度增加。更小的结尾更容易接上后续元素，所以替换只改善可扩展性，不损失已有长度。

## 跟着例子走一遍

[10,9,2,5,3,7,101,18] 的 tails 变化为 [10]、[9]、[2]、[2,5]、[2,3]、[2,3,7]、[2,3,7,101]、[2,3,7,18]，长度为 4。

## 写代码时注意什么

tails 本身不保证是原数组的一条实际子序列，只用来记录每个长度的最优结尾。严格递增要用 lower_bound；upper_bound 会把相等元素当作可延长。

## 复杂度

- 时间：O(n log n)。
- 空间：O(n)。
