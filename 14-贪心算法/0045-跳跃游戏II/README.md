# 45. 跳跃游戏 II

[力扣原题](https://leetcode.cn/problems/jump-game-ii/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

题目保证能到末尾，求最少跳跃次数。

## 怎么想到这个方法

**按可达区间分层扩展**

end 是当前跳数能覆盖的右边界，farthest 是在这一层所有位置再跳一步能到的最远处。扫描这一层里的所有位置，持续更新 farthest；到达 end 时，说明本层选择都看完了，必须增加一次跳跃，并将下一层边界设为 farthest。这相当于不显式建图的广度优先搜索。

## 跟着例子走一遍

[2,3,1,1,4]，第一次扫描位置 0 后，下一层边界是 2；扫描位置 1、2 时发现最远可到 4，第二次跳就能到末尾。

## 写代码时注意什么

只扫描到 n-2，末尾不用再起跳，否则会多计一次。代码依赖题目保证可达；若不保证，需要另外检查边界是否停止增长。

## 复杂度

- 时间：O(n)。
- 空间：O(1)。
