# 55. 跳跃游戏

[力扣原题](https://leetcode.cn/problems/jump-game/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

每个数表示从当前位置最多能跳多少步，判断是否能到达末尾。

## 怎么想到这个方法

**维护最远可达下标**

reach 表示目前能到达的最远位置。扫描下标 i，若 i>reach，当前位置根本到不了，后面也不可能到，立即失败；否则可从 i 继续跳，把 reach 更新为 max(reach,i+nums[i])。不必枚举具体跳法，所有可达位置形成连续前缀，最远边界就足够描述状态。

## 跟着例子走一遍

[2,3,1,1,4] 从 0 能到 2，扫描到 1 时又能扩展到 4，因此可达。对于 [3,2,1,0,4]，reach 最多为 3，扫描到 4 就失败。

## 写代码时注意什么

nums[i] 是最大跳长，不是必须跳这么远。遇到 0 不一定失败，只要之前的 reach 已越过它，就可以继续。

## 复杂度

- 时间：O(n)。
- 空间：O(1)。
