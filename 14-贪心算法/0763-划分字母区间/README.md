# 763. 划分字母区间

[力扣原题](https://leetcode.cn/problems/partition-labels/) · 中等 · [本类目录](../README.md) · [总目录](../../README.md)

## 要解决什么

把字符串分成尽可能多的段，使同一字母只出现在一段中，返回段长。

## 怎么想到这个方法

**用字符最后位置确定分段终点**

先记录每个字符最后出现的下标。扫描当前段时，end 取所有已遇字符最后位置的最大值，因为这些字符的后续出现必须包含在本段。i 到 end 时，当前段所有字母都不会再出现在后面，可以立即切开。越早在合法处切，段数越多。

## 跟着例子走一遍

ababcbacadefegdehijhklij 中，第一个 a 最后在 8，扫描过程中 b、c 都不要求超过 8，于是在 8 切出长度 9；后面再切出 7、8。

## 写代码时注意什么

不能只看当前字符是否最后出现，还要看本段所有字符要求的最远位置。题目为小写字母，因此用 26 长度数组即可。

## 复杂度

- 时间：O(n)。
- 空间：O(26)，不含输出。
